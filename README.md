# 🚀 SkillSwap - Platforma Wymiany Umiejętności

## Opis Aplikacji

**SkillSwap** to innowacyjna platforma webowa zaprojektowana, aby ułatwić użytkownikom **bezpośrednią wymianę umiejętności i wiedzy**. 

Idea jest prosta: zamiast płacić za kursy, możesz wymienić się tym, co wiesz, na to, czego chcesz się nauczyć.

* **Przykład:** Użytkownik A, który biegle posługuje się **Excelem**, może zaoferować lekcje w zamian za naukę **programowania** od Użytkownika B. Użytkownik B, znający **programowanie**, oferuje swoją wiedzę w zamian za opanowanie **Excela**.

Naszym celem jest budowanie społeczności, w której nauka jest dostępna dla każdego, a Twoje istniejące umiejętności stają się Twoją walutą.

## 💻 Dostępne Skrypty

W katalogu projektu możesz uruchomić następujące komendy:

### `npm install`

Zainstaluj wszystkie wymagane zależności przed uruchomieniem aplikacji.

### `npm start`

Uruchamia aplikację w trybie deweloperskim.
Otwórz [http://localhost:3000](http://localhost:3000) w przeglądarce, aby ją wyświetlić.

Strona zostanie automatycznie przeładowana po wprowadzeniu zmian. Ewentualne błędy lintowania (lint errors) będą widoczne w konsoli.

### `npm test`

Uruchamia runner testów w trybie interaktywnym z funkcją "watch".
Zobacz sekcję o [running tests](https://facebook.github.io/create-react-app/docs/running-tests) po więcej informacji.

### `npm run build`

Tworzy zoptymalizowaną kompilację (build) aplikacji w folderze `build`.
Poprawnie łączy (bundles) React w trybie produkcyjnym i optymalizuje kompilację pod kątem najlepszej wydajności.

Kompilacja jest zminimalizowana (minified), a nazwy plików zawierają hashe.
**Twoja aplikacja jest gotowa do wdrożenia (deployment)!**

Zobacz sekcję o [deployment](https://facebook.github.io/create-react-app/docs/deployment) po więcej informacji.

### `npm run eject`

**UWAGA: Jest to operacja jednokierunkowa. Po użyciu `eject` nie ma powrotu!**

Jeśli nie jesteś zadowolony z narzędzi i konfiguracji kompilacji, możesz użyć `eject` w dowolnym momencie. Ta komenda usunie pojedynczą zależność kompilacyjną z Twojego projektu, dając pełną kontrolę nad plikami konfiguracyjnymi (np. webpack, Babel).
